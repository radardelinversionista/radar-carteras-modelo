# Carteras modelo · Terminal del Radar

Este repositorio publica cada mes las carteras modelo por perfil que usa la Terminal del Radar del Inversionista.

- `modelo/modelo-datos.json`: carteras, supuestos de largo plazo y fondos por tramo. Lo genera el motor 4.2 y solo se publica si pasa los controles automáticos.
- `informes/`: el informe de controles de cada mes (`controles-AAAA-MM.json`) y el último (`ultimo.json`), se haya publicado o no.

No contiene datos de clientes ni el código del motor. Es material de análisis para el asesor, no una recomendación de inversión.
